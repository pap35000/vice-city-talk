    Πώς γράφεται ένα σενάριο

    @lang el            // γλώσσα φωνής: el, en, …
@theme sunset       // sunset, night ή studio
@cast Τάκης, Λένα   // αριστερός και δεξιός χαρακτήρας

# Τίτλος κλιπ
> Μικρή περιγραφή για την κάρτα του κλιπ
Τάκης: Απλή ατάκα.
Λένα [ok]: Ατάκα με πράσινη ετικέτα. {ΜΕΓΑΛΗ ΛΕΖΑΝΤΑ}
Τάκης [rep]: Κίτρινη ετικέτα. Το [unc] δίνει κόκκινη.
Λένα: Μένουν {{days}} μέρες ως τις 19/11/2026.

    Φωνές

    Η φωνή έρχεται από τη σύνθεση ομιλίας του browser σου. Ο Microsoft Edge έχει συνήθως ελληνικές φωνές. Στην καρτέλα «Χαρακτήρες» διαλέγεις φωνή για τον καθένα.

    Writing a script

    @lang en            // voice language: el, en, …
@theme night        // sunset, night or studio
@cast Tom, Lena     // left and right character

# Clip title
> Short description for the clip card
Tom: A plain line.
Lena [ok]: A line with a green tag. {BIG CAPTION}
Tom [rep]: Yellow tag. [unc] gives a red one.
Lena: {{days}} days until 19 Nov 2026.

    Voices

    Voices come from your browser's speech synthesis. Microsoft Edge usually ships the most languages. Pick a voice per character in the Characters tab.
